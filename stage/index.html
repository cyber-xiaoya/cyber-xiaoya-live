位置以歌词层为基准再往下 N px（默认 200，即 calc(50% + 200px)），水平居中、带阴影；矮窗口自动减行数（防被裁）。

弹幕主播模式

优先级：歌曲 > 打字聊天 > 弹幕——歌在播时弹幕和聊天回复都排队，等歌放完（或点「⏹ 停止演唱」）才继续。
节奏：每 N 秒挑最新一条弹幕 → 复读 → LLM 完整回答喂给数字人 → 说完才轮到下一条（中间弹幕被顶掉，不积压）。
送礼观众的弹幕优先插队，但同样遵守自己的 VIP 间隔（默认 5 秒）；仍不打断歌曲。点「保存设置」即时生效。
